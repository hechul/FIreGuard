# FireGuard 전원 및 신호 연결표

2026-10-26 / Raspberry Pi 4 / SparkFun TXS0108E / LRS-100-5 / WS2812B 155개.
사용자가 확인한 LED 선 색: 빨강 +5V, 하양 GND, 초록 DIN.
전원은 S1과 S10에 공급한다. 다음 표는 연결 관계이며 실제 핀의 배치 순서를 뜻하지 않는다.

| 출발 | 도착 | 용도 |
|---|---|---|
| LRS +V 첫 단자 | S1 별도 빨강 +5V | LED 전원 |
| LRS +V 다른 단자 | S10 +5| LRS -V 첫 단자 | S1 별도 하양 GND | LED 전원 귀환 |
V 패드 | 전원 보강 |
| LRS -V 다른 단자 | S10 GND 패드 | 전원 보강 |
| S1 3핀 커넥터 빨강 | TXS VB | 변환기 5V 전원 |
| S1 3핀 커넥터 하양 | TXS GND | 공통 GND |
| Pi 물리 1번 3.3V | TXS VA | 변환기 3.3V 전원 |
| TXS VA와 같은 3.3V 묶음 | TXS OE | 출력 활성화 |
| Pi 물리 6번 GND | TXS GND와 같은 묶음 | 공통 GND |
| Pi 물리 12번 BCM GPIO18 | TXS A1 | 제어 입력 |
| TXS B1 | 330Ω 저항 → S1 커넥터 초록 DIN | 제어 출력 |

S1 별도 빨강과 커넥터 빨강은 같은 +5V 연결점, 별도 하양과 커넥터 하양은 같은 GND 연결점이어야 한다.
LRS에서 TXS로 직접 가는 별도 전원선은 없지만, TXS의 VB는 S1 연결을 통해 LRS 전원을 받는다.
TXS 보드의 두 GND 핀은 공통이다. 핀헤더는 납땜한 뒤 브레드보드 중앙 홈을 가로질러 장착한다.
VA와 VB는 연결하지 않는다. OE는 3.3V로 연결한다. OE 처리법은 74AHCT125와 다르다.

Pi는 별도 USB-C 어댑터를 사용하며 Pi 5V 핀을 LED +5V에 묶지 않는다.
LED 전체 전류는 LRS에서 LED로 직접 공급한다. 브레드보드/점퍼선에는 TXS 전원과 제어 신호만 흐르게 한다.
18AWG 전원선을 연결하더라도 기존 LED의 가는 꼬리선·커넥터·납땜부 정격은 별도로 확인해야 한다.
전원 공급선과 접합부에 맞는 퓨즈를 선정하고, 점등 시 공급선별 전류와 끝단 전압을 확인한다.

LED 연결 순서는 S1→S2→…→S15. 각 구간 사이는 +5V→+5V, GND→GND, DOUT→DIN 세 가닥.
S10의 추가 전원 연결은 기존 S9 DOUT→S10 DIN 데이터 연결을 변경하지 않는다.
S15 DOUT은 연결하지 않는다. 데이터선을 두 DIN으로 나누지 않는다.

작업 전 Pi와 LRS의 전원을 분리한다. 이 문서는 DC/GPIO 연결도이며 AC 입력 시공도는 아니다.
TXS0108E는 짧은 배선으로 먼저 시험한다. 긴 선의 정전용량 때문에 불안정할 수 있으며,
깜빡임 발생 시 전원/접합/신호를 점검하고 NeoPixel용 74AHCT125 버퍼를 검토한다.

최종 도면은 `TXS-LRS-Pi-LED-배선도.svg`이다. 앞서 이미지 생성 도구가 만든 그림에는 전원 연결 오류가 있어 폐기했다.
