# Raspberry Pi → Flask 이벤트 계약

UI와 시뮬레이션은 이미 동일한 `SimulationState`를 사용합니다. 실제 배선이 끝나면 Raspberry Pi 센서 읽기 코드에서 아래 API만 호출하면 됩니다.

## Heartbeat

```http
POST /api/hardware/heartbeat
{}
```

## 불꽃 센서

실제 불꽃 입력은 센서별로 **1초 이상 연속 감지**가 확인된 후 화재로 반영합니다.
라즈베리파이는 상태가 바뀔 때만 보내지 말고, 모든 사용 중인 불꽃 센서의 현재 boolean 값을
**0.1~0.2초마다 반복 전송**하는 것을 권장합니다. 기존 1초 주기도 지원하지만,
샘플 사이에 잠깐 감지가 해제됐는지는 알 수 없습니다. 개별 API와 batch 모두 같은 판정을 사용합니다.

- 첫 true에서 계측을 시작하며 1초 이후의 true 수신 시 화재 알림과 경로 차단을 반영합니다.
- 확정 전 false는 누적 시간을 초기화합니다. 확정된 화재는 false를 받아도 유지합니다.
- 확정 전 같은 센서의 수신 간격이 1.5초를 초과하면 연속 감지로 보지 않고 다시 계측합니다.
- heartbeat나 다른 센서의 값으로 누적 시간을 연장하지 않습니다. true 한 번만 수신하고
  통신이 멈춘 경우 시간 경과만으로 화재를 확정하지 않습니다.
- SIMULATION의 버튼과 시나리오는 즉시 반영합니다. 시뮬레이션 초기화는 실제 계측을 지우지 않습니다.

이는 서버가 수신한 샘플 기준 판정입니다. 이미 확정된 화재를 통신 두절만으로 정상 해제하지 않습니다.

### 실제 화재 수동 해제

대시보드 상단의 `실제 화재 수동 해제`를 누르고 확인하면 현재 표시된 실제 화재 센서만 해제합니다.
REAL/SIMULATION 어느 모드에서도 가능하며, 시뮬레이션 상태에는 영향을 주지 않습니다.

```http
POST /api/real/fire/clear
{"sensorIds":["FLM-15"]}
```

확정된 화재는 정상값 수신, 센서/Pi 연결 단절, 모드 전환, 시뮬레이션 초기화로 해제되지 않습니다.
서버는 `runtime/real_fire_latches.json`에 확정 센서 ID를 저장해 재시작 후 복원합니다.
수동 해제 시 해당 센서의 확인 시간을 초기화하므로 감지가 계속되면 다시 1초 이상 확인 후 재경보합니다.
전송 프로그램에서 이 해제 API를 자동 호출하지 마세요.

```http
POST /api/hardware/flame
{"sensorId":"FLM-15","active":true}
```

## Batch

```http
POST /api/hardware/batch
{
  "flame":{"FLM-14":false,"FLM-15":true},
  "shutters":{"SH-01":false}
}
```

하드웨어 API는 실제 센서 상태만 갱신하며, Dashboard에서 선택한 모드를 자동으로 바꾸지 않습니다.

## 실제 센서 시연 후 시뮬레이션 시연

1. Dashboard의 REAL 버튼으로 실제 센서 관제를 선택합니다.
2. 실제 센서 감지와 정상 복귀를 확인합니다. 불꽃이 사라져도 라즈베리파이는 정상값과 heartbeat를 계속 전송합니다.
3. SIMULATION 버튼을 누르고 예외 상황 시나리오를 실행합니다.
4. 실제 센서가 계속 데이터를 보내도 시뮬레이션의 경로, 화재, 셔터 상태와 이벤트는 유지됩니다.
5. 실제 화재가 다시 감지되면 기존 실제 화재 알림이 표시됩니다. 사용자가 REAL 전환을 선택해야 관제 모드가 바뀝니다.

라즈베리파이 센서 수집 프로그램에서는 `/api/hardware/*`만 호출합니다. 반복 수집 루프에서 `/api/mode`로 REAL을 강제 선택하지 마세요.
이전에 사용하던 서버가 입력마다 REAL로 전환한다면 최신 서버로 교체하고 재시작해야 합니다.

실제 센서 상태와 시뮬레이션 상태는 별도로 보관합니다. 시뮬레이션 초기화는 실제 센서의 경보를 지우지 않습니다.

## 센서 구성 변경 (2026-10-28)

현재 프로젝트는 불꽃 센서만 사용합니다. MQ-2 개별 API는 제거됐으며, batch에 `mq2`를 보내면 상태 변경 없이 HTTP 400을 반환합니다. 라즈베리파이 수집 코드에서도 MQ-2 읽기와 전송을 제거하세요.
