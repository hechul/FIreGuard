# FIREGUARD 실제 LED 배선 기준 — 2026-10-26

기준: 사용자가 제공한 실제 모형 사진 `배선도.png`, 모형 900 × 600mm.
최신 변경: 사용자가 구간별 개수 총 155개를 확인했고, 전원 보강 위치를 S9에서 S10으로 변경했다.
사용자가 확인한 데이터 순서: S1 → S2 → … → S15.
이 문서는 이전 S1~S18 도면을 대체한다. 사진으로 실제 패드 방향과 납땜 품질을 검증한 것은 아니다.

## 구간 연결

모든 J 연결은 세 가닥이다: 앞 구간 +5V → 다음 +5V, GND → GND, DOUT → DIN.

| 연결 | 데이터 출발 | 데이터 도착 |
|---|---|---|
| J01 | S1 DOUT | S2 DIN |
| J02 | S2 DOUT | S3 DIN |
| J03 | S3 DOUT | S4 DIN |
| J04 | S4 DOUT | S5 DIN |
| J05 | S5 DOUT | S6 DIN |
| J06 | S6 DOUT | S7 DIN |
| J07 | S7 DOUT | S8 DIN |
| J08 | S8 DOUT | S9 DIN |
| J09 | S9 DOUT | S10 DIN |
| J10 | S10 DOUT | S11 DIN |
| J11 | S11 DOUT | S12 DIN |
| J12 | S12 DOUT | S13 DIN |
| J13 | S13 DOUT | S14 DIN |
| J14 | S14 DOUT | S15 DIN |

신호 변환기 출력 → 330Ω → S1 DIN. S15 DOUT 미연결.
데이터는 두 DIN으로 분기하지 않는다. 물리적 교차점은 전기적 접속점이 아니다.

## 전원

같은 LRS-100-5의 +V 단자 두 개와 -V 단자 두 개를 이용한다.

| 전원 출력 | 도착 |
|---|---|
| +V 첫 단자 | S1 +5V |
| -V 첫 단자 | S1 GND |
| +V 다른 단자 | S10 +5V |
| -V 다른 단자 | S10 GND |

S10 전원 추가 시 J09의 기존 세 가닥은 유지한다. 추가 전원은 +5V와 GND에만 연결한다.
라즈베리파이와 신호 변환기의 GND를 LED 전원 GND와 공통 연결한다.
별도 어댑터로 구동하는 라즈베리파이의 +5V와 LED 전원의 +V를 연결하지 않는다.
전원장치 보호접지 기호와 DC -V는 구분한다. 이 문서는 AC 입력 시공도가 아니다.

## 전선과 확인 범위

- 전원 공급선: 각 1m 이내의 18AWG 동선 연선 권장안. 실제 개수는 155개로 확정되어 60mA/개 보수적 가정의 최대 부하는 9.3A이다. 공급선별 전류, 접속부와 끝단 전압을 확인해야 한다.
- 두 전원 입력의 전류가 정확히 절반씩 나뉜다고 가정하지 않는다.
- 22AWG 구간 전원선은 뒤쪽 LED까지 포함한 통과 전류를 확인한다.
- 24AWG는 구간 사이 데이터 연결에 사용한다.
- 전원선별 퓨즈는 실제 배선과 접속부의 허용 전류에 맞춰 선정한다.
- 기존 가는 공장 전원선과 커넥터에 굵은 선을 이어도 그 부분의 허용 전류가 증가하지 않는다.
- 각 패드의 위치와 DIN/DOUT 끝은 실물 인쇄로 확인한다. 도면의 위치 그림만 보고 결정하지 않는다.
- 전원을 분리하고 작업하며 납땜 접합부는 각각 절연하고 당김을 받지 않게 고정한다.

## 그림 제작 기록

내장 이미지 생성 도구로 실제 사진을 기준으로 배치도를 재작성했다.
제작 지시 요약: 실제 S1~S15 배치를 유지하고 14개 구간 연결표, 구간 사이 3선 연결, LRS의 S1/S10 이중 전원 공급, 공통 GND, 최초 330Ω 저항, 마지막 DOUT 미연결 및 실물 패드 확인 주석을 표시한다.
